## What's Changed

**Avoid ChatGPT startup warnings before first sign-in**

If you have never connected ChatGPT, PowerSync now waits until you choose **Continue with ChatGPT** before saving connection details. This avoids an unnecessary startup warning when that first save is unavailable. This change does not repair storage problems affecting an existing ChatGPT connection.

Update available via HACS
