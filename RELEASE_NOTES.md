## What's Changed

**Enphase solar stopping preserves the gateway control mode**
Stopping solar during negative import prices now accepts readable settings from either static Gateway mode or digital-input relay mode, keeps the selected mode, and restores the previous settings, including after an upgrade. Confirmation of a saved limit still does not prove that solar production has stopped; fresh solar readings are required.

Update available via HACS
